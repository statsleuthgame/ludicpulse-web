Common setup fixes

  • If automatic tracking is not ready, wake the vehicle, open Car → Settings → Tesla connected, and retry the indicated setup stage.
  • If data is stale, use the Car refresh button once. Ludic Pulse avoids constant Tesla polling while telemetry is healthy.
  • If a command is accepted but not confirmed, check the Tesla app or vehicle before repeating it.
  • Share ETA appears only while Tesla navigation has a fresh destination. A link ends when you arrive, cancel navigation, change destination, stop it in Ludic Pulse, or reach four hours.
  • For Hub footage, stand near the powered Hub and let Ludic Pulse join its private Wi-Fi. Cellular service remains available.
